Unofficial demo · not affiliated with TypeSafe AI

Typed decisions, one pass, no parsing

Reproducing the parallel constrained decoding idea behind Jev (TypeSafe AI's "System One" model) on a stock 1.5B model, on a laptop. Instead of generating JSON token-by-token, all schema fields are evaluated in one batched forward pass and the JSON is assembled programmatically — so it can never be malformed.

How it works

[context + schema] ──► prefill (once) ──► KV cache
                                            │ broadcast × N fields
      ┌───────────┬───────────┬─────────────┴───────────┐
    field 1     field 2     ...                      field N
      └───────────┴──── one batched forward pass ────────┘
                          │
              slice logits → softmax → pick value + probability
